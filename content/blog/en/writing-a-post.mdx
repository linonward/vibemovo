1. Add `content/blog/en/<slug>.mdx`. Use lowercase letters, digits and hyphens for the slug.
2. Start the file with its metadata: a `title`, a one-sentence `description` and a `date` as `YYYY-MM-DD`.
3. Write the body in Markdown. Headings start at `##`, because the title is the page's only `#`.

The blog lists posts newest first, by `date`. This post exists in English only, so the Chinese blog doesn't list it.
