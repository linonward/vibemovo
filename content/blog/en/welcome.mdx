Each post is an MDX file under `content/blog/<locale>/`. The file name is the URL: `welcome.mdx` opens at `/en/blog/welcome`.

## Posts per language

Every language has its own posts. A post that exists in English only doesn't show up in the Chinese blog. Give two translations of a post the same file name, so they share a URL.
