## 改进模式

1. **先地基后功能**：流程、测试、CI 早于大部分功能。
2. **先闭环后扩展**：账户 → 积分 → 支付先通，再加 AI。
3. **构建 → 审计 → 修复 → 重构 → 文档对齐**，循环两轮（S70–S88、S99–S109）。
4. **修复占比约 17%**（25 / 144），集中在安全、计费原子性、数据归属。
5. **体验持续回炉**：落地页、侧边栏、定价页都经历了多次改版。
6. **最后做性能**：功能稳定后再优化渲染、查询和网络请求。
